# سجل القراءة — Reading Record

إعداد وتصميم منسقة الروضة أ. مريم المعمري · مدرسة الطليعة

A static, GitHub Pages-ready copy of the reading record program. This is a working application with bundled dependencies and artwork, not a screenshot. The interface is Arabic and right-to-left.

## Publish with GitHub Pages

1. Extract the ZIP on your computer.
2. Create a GitHub repository.
3. Upload the **contents** of `reading-record-github` to the repository root. `index.html` must be at the root, alongside `app.js`, `styles.css`, and the `assets` folder. Do not upload only the ZIP or only `index.html`.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select **main** and **/(root)**, then click **Save**.
7. Open the URL shown by GitHub Pages when deployment finishes. Allow the camera when using the scanner.

No terminal, installation, or build step is required to publish the included files. Relative asset paths work for repository sites such as `https://USERNAME.github.io/REPOSITORY/`.

## Features

- Add students and select their class: KG1A, KG1B, KG2A, KG2B.
- Assess stories, sight words, and letters at four levels: E, D, P, M.
- Save dated assessments and teacher notes.
- Show each student's history, skill progress chart, and printable report.
- Generate and print student QR codes, individually or for the class.
- Scan a student code to select their record in the same browser data store.

## Data and QR codes

This copy uses `localStorage` on the current browser/device. It does **not** connect to the original site's database and does **not** synchronize records between devices, teachers, browsers, or websites. It starts with an empty record and includes no student data.

A student QR code links to this GitHub Pages deployment with the student's identifier. Scanning it on a different device will not transfer the student's name or assessments. That device must already have matching records; a shared server database is needed for cross-device use.

Clearing browser/site data can erase records. Private browsing and storage restrictions may prevent persistence. Camera scanning requires HTTPS (GitHub Pages supplies it) or localhost. Generate QR codes after publishing so that they use your final GitHub Pages URL.

## Files and editing

| File | Purpose |
| --- | --- |
| `index.html` | Readable HTML entry point |
| `styles.css` | Colors, layout, responsive styling, and print styling |
| `app.js` | Ready-to-use JavaScript, including React, QR generation, and camera scanner |
| `assets/reading-cartoon-header.png` | Original cartoon header artwork |
| `src/Page.tsx` | Readable application source: interface, chart, reports, and QR behavior |
| `src/storage.ts` | Local student and assessment storage |
| `package.json` | Optional build command and dependency versions |

The UI is implemented with React, so HTML is the entry point and the interactive page is generated by JavaScript. For layout colors or typography, edit `styles.css` directly. For behavior or interface text, edit `src/Page.tsx` or `src/storage.ts`, then rebuild `app.js`:

```sh
npm install
npm run build
```

Commit the updated `app.js` along with the changed source. The included `app.js` has already been built. Dependency license notices are preserved in that file.
